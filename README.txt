Wärmezeit – WebApp / PWA

Dateien:
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

Installation auf dem iPhone:
1. Alle Dateien auf einen HTTPS-Webspace hochladen.
2. Die Adresse in Safari öffnen.
3. Teilen -> Zum Home-Bildschirm -> Hinzufügen.
4. Danach startet Wärmezeit wie eine normale App und funktioniert nach dem ersten Laden auch offline.

Funktionen:
- beliebig viele Prozessschritte
- Aktion / Temperatur / Stunden / Minuten pro Schritt
- Reihenfolge ändern und Schritte löschen
- Gesamtzeit automatisch aus den Schritten
- Zielzeit vorgeben -> Startzeit berechnen
- Startzeit vorgeben -> Endzeit berechnen
- Live-Wartezeit / Restzeit
- kompletter Zeitplan
- eigene Programme lokal speichern
- Kalenderdatei mit 10-Minuten-Erinnerung
- Offline-Betrieb nach erster Installation

Beispiel:
300 °C Aufheizen 1:30
300 °C Halten 1:00
450 °C Aufheizen 0:45
450 °C Halten 1:00
505 °C Aufheizen 0:45
505 °C Halten 1:00
Gesamt: 6:00 h
